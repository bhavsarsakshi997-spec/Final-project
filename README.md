# COVID-19 Data Analysis and Visualization

## 1. Introduction

The **COVID-19 Data Analysis and Visualization** project is a Python-based data analysis project developed to analyze COVID-19 related information from a CSV dataset.

The project focuses on analyzing important COVID-19 statistics such as **Confirmed Cases, Recovered Cases, and Deaths**. It also performs country-wise analysis to identify countries with high numbers of confirmed cases.

The project uses Python libraries such as **Pandas, NumPy, Matplotlib, and Seaborn**. Pandas is mainly used for data handling and analysis, NumPy is used for numerical calculations, and Matplotlib and Seaborn are used for data visualization.

The project also analyzes COVID-19 data according to dates to understand how cases, recoveries, and deaths change over time.
